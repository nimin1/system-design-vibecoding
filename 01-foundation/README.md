---

## How This Connects to AI Tools

The concepts here let you write more specific prompts. Instead of:

> "Build me an app that saves data"

You can say:

> "Build a REST API with POST/GET/PUT/DELETE endpoints, PostgreSQL storage, and appropriate HTTP status codes"

The second prompt gives the AI enough context to produce something reasonable.
