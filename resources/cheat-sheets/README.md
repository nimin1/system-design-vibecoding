| [Interview Cheat Sheet](interview-cheat-sheet.md) | Framework, patterns, components | Interview prep, last-minute review |

## How to Use

**Before interviews:** Review the interview cheat sheet for the framework and common patterns.

**During estimation:** Reference the numbers sheet for latency, capacity, and conversions.

**For quick lookup:** Keep these open during system design work.
