# Contributing

If you find a mistake or want to improve something, contributions are welcome.

---

## Types of Contributions

**Fixes:** Typos, factual errors, broken links.

**Clarifications:** If an explanation is confusing, suggest improvements.

**Additions:** New examples, diagrams, or sections.

---

## Guidelines

**Keep the tone grounded.** Write like you're explaining to a colleague, not marketing to a customer. Avoid hype and buzzwords.

**Be accurate.** Don't invent facts or statistics. If you're not sure about something, say so or leave it out.

**Keep it practical.** Focus on things that help readers understand or apply the concepts.

---

## Process

1. Open an issue describing what you want to change
2. Fork the repo
3. Make your changes
4. Submit a pull request
