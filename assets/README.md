# Assets

This folder contains all visual assets for the repository:

- `diagrams/` - Architecture diagrams and visual explanations

## Adding Assets

When adding new diagrams:

1. Use consistent styling (see existing diagrams)
2. Use PNG format for best compatibility
3. Include a descriptive filename
4. Keep file sizes reasonable (optimize images)

## Diagram Tools

Recommended tools for creating diagrams:
- [Excalidraw](https://excalidraw.com/) - Hand-drawn style
- [Draw.io](https://draw.io/) - Professional diagrams
- [Mermaid](https://mermaid.js.org/) - Diagrams as code
