## Approach

Each design follows a consistent structure:

1. **Clarify requirements**  -  Functional and non-functional
2. **Estimate scale**  -  Back-of-envelope calculations
3. **High-level architecture**  -  Components and data flow
4. **Deep dive**  -  Key components and algorithms
5. **Trade-offs**  -  What decisions were made and why
6. **Common mistakes**  -  What to avoid
7. **Senior-level thinking**  -  What senior engineers consider

This mirrors system design interviews but focuses on real understanding.
